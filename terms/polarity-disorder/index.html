Combat mechanic

Polarity Disorder

A special Disorder-like trigger that deals extra damage without removing the active Attribute Anomaly.

2 linked sources checked 2026-08-20

Definition

How it works

  1. An eligible Attribute Anomaly is active on the enemy.
  2. A compatible Agent skill triggers Polarity Disorder.
  3. It deals additional damage while leaving the active anomaly in place.

Why it matters

What it changes

Because it does not replace the active anomaly, Polarity Disorder does not follow the same state transition as normal Disorder and must be modeled separately.

Active anomaly retained
The target keeps the Attribute Anomaly that enabled the trigger.
Kit-defined damage
The compatible Agent's skill defines the exact scaling and conditions.

Common confusion

It does not consume the active anomaly

Normal Disorder replaces the first anomaly when another eligible one is inflicted. Polarity Disorder is skill-triggered and leaves the active anomaly in place.
