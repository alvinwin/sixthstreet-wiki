Combat mechanic

Abloom

A named mechanic used by certain Agent skills to deal additional damage from an existing Attribute Anomaly.

2 linked sources checked 2026-08-20

Definition

How it works

  1. An Attribute Anomaly is active on the target.
  2. An Agent skill with an Abloom trigger meets its conditions.
  3. Abloom deals additional Attribute Anomaly damage using that skill's own calculation.

Why it matters

What it changes

Abloom is a real shared label, but not a universal reaction with one fixed multiplier. Its trigger and scaling must be read from the Agent skill that produces it.

Existing anomaly
Abloom derives damage from an Attribute Anomaly already present on the target.
Skill-defined scaling
The triggering Agent's skill defines the exact damage calculation.

Common confusion

A category, not a free reaction

An ordinary Attribute Anomaly does not automatically cause Abloom. A compatible Agent skill has to trigger it, and different implementations can use different ratios.
